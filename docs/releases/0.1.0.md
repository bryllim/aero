Aero's first public preview. A native macOS desktop clock with airport-inspired displays, Pomodoro, and live system stats.

Developed by **[Bryl Lim](https://bryllim.com)**. Source, original artwork, and documentation are licensed under **[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)**.

### Features

- Dot matrix and split-flap styles, themes, transparency, and screen placement.
- Clock, departures board, and daylight world map layouts.
- Pomodoro sessions and breaks, with a monochrome menu bar card and countdown.
- Optional CPU, RAM, and swap readings directly on the wallpaper.
- Multiple displays, launch at login, and optional Claude Code and Codex usage readings.
- Restoring appearance preserves timer and feature preferences.

### Install

Download **Aero-0.1.0-universal.dmg**, open it, and drag Aero into Applications. Requires **macOS 14 or later**, on Apple silicon or Intel. `SHA256SUMS.txt` contains the download checksum.

### Preview status

The app is **ad hoc signed and not notarized**. macOS may block it when downloaded. Developer ID signing and notarization are still needed for installation through the normal Gatekeeper flow. Building from the published source is also supported.

Release builds and regression checks have been verified locally. Visual layouts were rendered in light and dark appearances. Full first-install testing of permissions, notifications, login startup, sleep/wake, and multiple displays remains outstanding. Intel is included in the universal binary; live Intel testing remains outstanding. AI usage integrations are optional and depend on existing CLI sign-ins and provider endpoints that can change. Updates are installed manually from GitHub Releases.
