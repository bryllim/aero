# Aero

A native macOS desktop clock inspired by airport displays, with dot matrix and split-flap styles, world clocks, and a Pomodoro timer.

Developed by **[Bryl Lim](https://bryllim.com)**.

Requires macOS 14 or later. Open `Aero.xcodeproj` in Xcode to build and run.
